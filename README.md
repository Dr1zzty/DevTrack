# DevTrack

A task management API for workplaces.

## Features

- Create task with titles, descriptions, priorities, and due dates.
- Retrieve task individually or as a list.
- Update task informations and status.
- Soft-delete task without permanently removing them from the database.
- Track task completion dates and whether task were completed late.

## Technologies 

- C#
- .NET 10
- ASP.NET Core Web API
- Entity Framework Core
- SQLite

## Getting Started

2. Navigate to the project directory.
